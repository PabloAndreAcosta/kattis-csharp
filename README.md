# kattis-csharp

Lösningar till problem på [Kattis](https://open.kattis.com), skrivna i C#.

Repot hör till test- och kartläggningsveckorna inför IT-påbyggnadsutbildningen
Fullstackutvecklare .NET hos Lexicon, september 2026.

## Lösningar

| Problem | Mapp | Status |
|---|---|---|
| [FizzBuzz](https://open.kattis.com/problems/fizzbuzz) | `fizzbuzz/` | pågår |

## Köra en lösning

```
cd fizzbuzz
dotnet run
```

Programmet läser sin indata från terminalen. Skriv in raden med tal och tryck enter.
