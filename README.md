# kattis-csharp

Lösningar till problem på [Kattis](https://open.kattis.com), skrivna i C#.

Repot hör till test- och kartläggningsveckorna inför IT-påbyggnadsutbildningen
Fullstackutvecklare .NET hos Lexicon, september 2026.

Kattis-profil: https://open.kattis.com/users/pablo-acosta

## Lösningar

| Problem | Mapp | Status |
|---|---|---|
| [FizzBuzz](https://open.kattis.com/problems/fizzbuzz) | `fizzbuzz/` | löst |
| [Hello World!](https://open.kattis.com/problems/hello) | `hello/` | Accepted |
| [Stuck In A Time Loop](https://open.kattis.com/problems/timeloop) | `timeloop/` | Accepted, 9/9 |
| [Odd Echo](https://open.kattis.com/problems/oddecho) | `oddecho/` | pågår |

## Köra en lösning

```
cd timeloop
dotnet run
```

Programmet läser sin indata från terminalen. Skriv in raden och tryck enter.

## Vad som är vad i repot

**Lösningarna är mina.** `fizzbuzz/`, `hello/`, `timeloop/` och `oddecho/`
innehåller kod jag skrivit själv, rad för rad. Kommentarerna i filerna är
avsiktliga — de visar hur jag brutit ner problemet innan jag skrev lösningen.

**`ovningar/` är studiematerial.** Mappen innehåller genomgångar jag arbetat
mig igenom under veckan, framtagna åt mig med hjälp av ett AI-verktyg som
lärare. De är inte lösningar och inte mitt eget arbete — de är läromedel, och
de ligger här för att de hör till hur jag lärt mig.

Jag har hållit isär de två sakerna i historiken också: commits som rör
studiematerialet är märkta med verktyget som medförfattare, commits med mina
lösningar är inte det.

## Om arbetssättet

Jag började veckan utan att kunna skriva C# själv. När ett steg visat sig för
stort har jag brutit ned det i mindre övningar och arbetat mig uppåt — det är
vad häftena i `ovningar/` är. Commit-historiken visar ordningen och takten.
